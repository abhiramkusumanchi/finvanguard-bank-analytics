Data Warehouse Queries (SQL)

Select a query below to inspect the database code powering the dashboard

-- Query 1: Calculate Total Bank Loans and Late Payments by Loan Type
SELECT 
    loan_type,
    COUNT(loan_id) AS total_loans_given,
    SUM(principal_amount) AS total_money_loaned_usd,
    ROUND(AVG(interest_rate_pct), 2) AS avg_interest_rate,
    SUM(CASE WHEN days_past_due >= 90 THEN principal_amount ELSE 0 END) AS defaulted_loans_usd
FROM fact_loans
GROUP BY loan_type
ORDER BY total_money_loaned_usd DESC;
