1. Executive Summary & Problem Solved

Banks face two existential threats to profitability: Credit Loan Defaults (bad borrowers who stop paying) and Deposit Flight (high-value customers taking their savings to competitor banks). FinVanguard 360° is an end-to-end analytics platform that monitors $1.35 Billion in Assets Under Management (AUM), models credit risk via an automated underwriting scorecard, flags $115.9 Million in deposit flight risk, and provides an interactive macroeconomic stress-test simulator.

4. The 5 Core SQL Queries Explained

Query 1: Bank Portfolio Rollup & Weighted Yield

SELECT 
    loan_type,
    COUNT(loan_id) AS total_loans_given,
    SUM(principal_amount) AS total_disbursed_usd,
    ROUND(SUM(principal_amount * interest_rate_pct) / NULLIF(SUM(principal_amount), 0), 2) AS weighted_avg_rate_pct,
    SUM(CASE WHEN days_past_due >= 90 THEN principal_amount ELSE 0 END) AS defaulted_loans_usd
FROM fact_loans
GROUP BY loan_type
ORDER BY total_disbursed_usd DESC;

Why it works: Uses NULLIF to prevent division-by-zero and calculates weighted averages so large mortgages ($500k) weigh properly against small personal loans ($5k).

Query 2: Finding Accounts Late on Loans (30+ Days)

SELECT 
    customer_id, loan_type, principal_amount, days_past_due, monthly_installment
FROM fact_loans
WHERE days_past_due >= 30
ORDER BY days_past_due DESC
LIMIT 10;

Query 3: Customer Churn & Inactivity

WITH CustomerActivity AS (
    SELECT c.customer_id, c.account_tier, c.deposit_balance,
           COALESCE(EXTRACT(DAY FROM ('2026-03-01'::timestamp - MAX(t.transaction_timestamp))), 365) AS days_inactive
    FROM dim_customer c
    LEFT JOIN fact_transactions t ON c.customer_id = t.customer_id
    GROUP BY c.customer_id, c.account_tier, c.deposit_balance
)
SELECT * FROM CustomerActivity WHERE days_inactive >= 90 AND deposit_balance >= 25000;

Why it works: Isolates accounts holding $25,000+ that haven't transacted in 90+ days (the leading indicator of deposit flight).

5. Mathematical & Risk Models

1. Loan Amortization (Monthly EMI):

PMT = P * [r(1+r)^n] / [(1+r)^n - 1]

Calculates monthly payment from principal, interest rate, and term months.

2. Basel II Expected Loss:

EL = PD * LGD * EAD

PD = Probability of Default, LGD = Loss Given Default (20% for mortgage, 50% for unsecured), EAD = Exposure at Default.

3. Model Discrimination:

ROC-AUC = 0.715 | KS Statistic = 33.2%

Separates good borrowers from bad borrowers effectively (regulatory benchmark is >30%).

4. Scorecard Scaling:

Score = 600 + (50 / ln(2)) * ln((1-PD)/PD)

Converts logistic default probability into standard 300 - 850 credit bureau points.
